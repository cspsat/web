プログラム

3月23日(月)  
13:30 - 14:30 SIG-FPAI 招待講演 モデル生成型定理証明系とSATソルバー
  長谷川隆三（九州大学） [PDF]
3月23日(月)  
15:15 - 15:30 オープニング
15:30 - 16:10 講演1 　 離散構造処理系プロジェクトの主な研究成果と今後の展望 　
  湊真一 (北海道大学) 　[概要]

今年度までの5年間にわたってERATO湊離散構造処理系プロジェクトが実施され、BDD/ZDDを中心とした離散構造処理の技法とその応用に関する多くの研究成果が得られている。本講演では、離散構造処理系プロジェクトの主要な成果について説明するとともに、SATや制約プログラミング技術と関連する今後の課題について述べる。
[PDF]
16:10 - 16:50 講演2 　メタレベル・アブダクションの論理　
  井上克巳 (国立情報学研究所) 　[概要]

メタレベル・アブダクションは，因果性の論理に関するメタ公理を用いて，証明を補完し観測をメタレベルで説明するための手法として提案され，隠れ規則の発見や生体ネットワークの補完に応用されている．本研究では，メタレベル・アブダクション を一般化し，新たな公理系を与え，提案されている種々のアブダクションのパターンに関する解析を行う．
[PDF]
16:50 - 17:10 20分休憩
17:10 - 17:50 講演3 　制約付きマッチングのメカニズムデザイン　　
  横尾真 (九州大学) 　[概要]
共同研究者名: 小島 武仁 (スタンフォード大)，田村 明久 (慶應大学)

マッチング理論は研修医と病院をマッチする研修医配属問題等の様々な応用問題を扱える一般的な枠組みであり，著名なメカニズムとしてDeferred Acceptance (DA) メカニズムがある．しかしながら，現実の問題では，マッチングの結果になんらかの制約条件が課せられることが通例であり，DAメカニズムをそのまま適用することはできない．本講演ではこのような制約付きマッチングでのメカニズム設計について解説する．
[PDF]
17:50 - 18:30 講演4 　制約充足問題のハイブリッド符号化のための枠組み　
  田村直之 (神戸大学) 　[概要]
共同研究者: 番原睦則，宋剛秀 (神戸大学)

制約充足問題をSATあるいはPBに符号化する方法として，2進符号化，直接符号化，順序符号化など様々な方法が提案されている．しかし，各々の符号化には適不適があり，すべての制約充足問題に適した単一の符号化は存在していない．したがって，複数の符号化を混在させたハイブリッド符号化に関する研究が重要となる．そこで，本講演では上記の符号化を任意に組合せることが可能なハイブリッド符号化のための理論的な枠組みを提案する．
[PDF]
19:00 - 懇親会
3月24日(火)  
09:30 - 10:10 講演5 　分散探索による船舶衝突回避　 　　　　
  平山勝敏 (神戸大学) 　[概要]
共同研究者: 金東均，沖本天太 (神戸大学)

海上では意外なほど多くの船舶衝突事故が発生している．一般に船舶は運動性能が鈍くかつブレーキを持たない．そのため，特に３隻以上の船舶が互いにすれ違う複雑な状況では，衝突回避のために高度かつ迅速な判断を求められ，それが操船者への大きな負担となっている．本研究では，分散探索の技術を用いて衝突回避タスクを自動化することにより操船者の負担軽減を目指す．
[PDF]
10:10 - 10:50 講演6 　SAT ソルバーと動的簡単化手法　
  鍋島英知 (山梨大学) 　[概要]

SAT 問題の簡単化は，SAT ソルバーの重要な要素技術の1つである．本講演では，SAT ソルバーにおいて頻繁に繰り返される処理に便乗して SAT 問題を簡単化する軽量な手法を紹介し，それを実装したソルバー GlueMiniSat の現状を報告する．
[PDF]
10:50 - 11:10 20分休憩
11:10 - 11:50 講演7 　MGTPとQMaxSAT
  越村三幸 (九州大学) 　[概要]

MGTPはモデル生成法に基づく一階述語論理の定理証明システムであり，極小モデル完全性を有する．本講演では，MGTPとCDCLベースのSATソルバーの関連性について述べるとともにMaxSATソルバーQMaxSATの現状について報告する．
[PDF]
11:50 - 12:00 クロージング
